### 🔐 VIGIL — API Key Management Platform

**Next.js • Express.js • MongoDB • Redis • BullMQ • Passport.js**

A secure API key management and monitoring platform.

* 🔑 API key creation and management
* 🔒 **AES-256-GCM encryption** for stored API keys
* 🛡️ Plaintext API keys are never stored on disk
* 🔐 Google OAuth authentication
* 🍪 JWT authentication using **HttpOnly + SameSite cookies**
* 🔄 Automatic token rotation
* ⚙️ Redis + BullMQ workers for quota and background processing
* 📡 Server-Sent Events for real-time API status updates
* ❤️ Health monitoring and response-time tracking
* 🚨 Threshold-based alerts
